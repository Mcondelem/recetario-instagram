# Recetario Instagram API

Backend Java con Spring Boot para la app Recetario Instagram.

## Requisitos

- Java 21
- Maven 3.9+

## Desarrollo

Desde `apps/api`:

```bash
mvn spring-boot:run
```

La API escucha en:

```text
http://localhost:8080
```

Endpoint inicial:

```text
GET /health
```

## Tests

```bash
mvn test
```
